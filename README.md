# Фруктові Обчислення

Гра на розвʼязання систем рівнянь із фруктовими емодзі. Кожне рівняння
вводить один новий фрукт, тож система розвʼязується послідовно зверху вниз.
Учень вписує значення кожного фрукта й перевіряє відповідь.

## Рівні складності

| Рівень       | Фрукти | Значення | Результати | Операції        |
| ------------ | ------ | -------- | ---------- | --------------- |
| 1 · Легкий   | 3      | 1–5      | 1–10       | +               |
| 2 · Середній | 3      | 1–10     | 1–20       | +, −            |
| 3 · Складний | 3      | 1–20     | 1–50       | +, −            |
| 4 · Експерт  | 4      | 1–20     | 1–50       | +, −            |
| 5 · Майстер  | 5      | 1–10     | 1–100      | +, −, ×         |

Обраний рівень запамʼятовується в браузері. Параметри рівнів задані в масиві
`LEVELS` на початку `logic.js`.

Застосунок повністю клієнтський (HTML, CSS, JS) і розміщений на GitHub Pages:
<https://fruzenshtein.github.io/math-problems/>

## Локальний запуск

Відкривати `index.html` подвійним кліком не варто: у macOS браузер не отримає
доступу до сусідніх файлів `logic.js` і `styles.css`. Запустіть статичний
сервер у теці проєкту:

```bash
python3 -m http.server 8000
```

і відкрийте <http://localhost:8000>.

## Структура

| Файл         | Призначення                                  |
| ------------ | -------------------------------------------- |
| `index.html` | Розмітка: стартовий екран і екран завдання   |
| `logic.js`   | Генерація рівнянь і перевірка відповідей     |
| `styles.css` | Невеликі доповнення до стилів Bootstrap      |
