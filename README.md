# Фруктові Обчислення

Гра на розвʼязання систем рівнянь із фруктовими емодзі. Три фрукти,
три рівняння, учень знаходить значення кожного фрукта й перевіряє відповідь.
Усі результати рівнянь лежать у межах від 1 до 20.

Застосунок повністю клієнтський (HTML, CSS, JS) і розміщений на GitHub Pages:
<https://fruzenshtein.github.io/math-problems/>

## Локальний запуск

Відкривати `index.html` подвійним кліком не варто: у macOS браузер не отримає
доступу до сусідніх файлів `logic.js` і `styles.css`. Запустіть статичний
сервер у теці проєкту:

```bash
python3 -m http.server 8000
```

і відкрийте <http://localhost:8000>.

## Структура

| Файл         | Призначення                                  |
| ------------ | -------------------------------------------- |
| `index.html` | Розмітка: стартовий екран і екран завдання   |
| `logic.js`   | Генерація рівнянь і перевірка відповідей     |
| `styles.css` | Невеликі доповнення до стилів Bootstrap      |

Межі значень задані константами `MIN_VALUE`, `MAX_VALUE`, `MIN_RESULT`
і `MAX_RESULT` на початку `logic.js`.
