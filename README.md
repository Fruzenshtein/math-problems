# Фруктові Обчислення

Гра на розвʼязання систем рівнянь із фруктовими емодзі. Учень вписує
значення кожного фрукта й перевіряє відповідь.

На рівнях 1–3 кожне рівняння вводить один новий фрукт, тож система
розвʼязується послідовно зверху вниз. На рівнях 4 і 5 усі фрукти входять
у кожне рівняння, наприклад 🍏 + 🍊 − 🍋 + 🍐 = 21, а генератор перевіряє
перебором, що система має рівно один розвʼязок у дозволених межах.

## Рівні складності

| Рівень       | Фрукти | Значення | Результати | Операції        |
| ------------ | ------ | -------- | ---------- | --------------- |
| 1 · Легкий   | 3      | 1–5      | 1–10       | +               |
| 2 · Середній | 3      | 1–10     | 1–20       | +, −            |
| 3 · Складний | 3      | 1–20     | 1–50       | +, −            |
| 4 · Експерт  | 4 у кожному рівнянні | 1–20 | 1–50 | +, − |
| 5 · Майстер  | 5 у кожному рівнянні | 1–10 | 1–100 | +, −, × (одне на рівняння) |

Обраний рівень запамʼятовується в браузері. Параметри рівнів задані в масиві
`LEVELS` на початку `logic.js`.

Застосунок повністю клієнтський (HTML, CSS, JS) і розміщений на GitHub Pages:
<https://fruzenshtein.github.io/math-problems/>

## Локальний запуск

Відкривати `index.html` подвійним кліком не варто: у macOS браузер не отримає
доступу до сусідніх файлів `logic.js` і `styles.css`. Запустіть статичний
сервер у теці проєкту:

```bash
python3 -m http.server 8000
```

і відкрийте <http://localhost:8000>.

## Структура

| Файл         | Призначення                                  |
